Mixture of Cognitive Reasoners · clean-room replication

Who should think about this token?

MiCRo replaces one monolithic reasoning path with a router that dispatches token representations to specialized expert modules: Language, Logic, Social, and World.

Hover or click a token. The underline shows its expert lane.

Language

Linguistic and expression-oriented processing.

Logic

Formal, relational, and reasoning-oriented processing.

Social

Signals involving people, intent, tone, and social context.

World

Broader contextual and world-knowledge-oriented processing.

Only the five explicitly documented assignments in the README are presented as repository-supported sample routes. The remaining token colors are included to make the interaction visually complete and should be treated as illustrative, not measured router output.
02 · What happens inside one MiCRo layer
512-d token representation
→
MLP router
→
Top-1 expert: Language / Logic / Social / World

The implementation computes four router logits per token, selects the highest-scoring expert with argmax, and passes that token representation through only the selected expert block.
